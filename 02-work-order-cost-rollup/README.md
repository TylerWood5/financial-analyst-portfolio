# Silver Sands Resort & Casino Work Order Cost Rollup

## Business Problem

Facilities leadership needed visibility into maintenance spending across departments, work types, and vendors in order to better understand operational costs and support budgeting decisions.

## Solution

Built a maintenance cost reporting model by combining work order transactions, labor rate schedules, and vendor invoice data. Developed cost rollups, vendor spend analysis, PivotTable summaries, and dashboard reporting.

## Skills Demonstrated

- XLOOKUP
- Data Integration
- Pivot Tables
- Pivot Charts
- Dashboard Development
- Cost Rollups
- Vendor Spend Analysis
- Operational Reporting
